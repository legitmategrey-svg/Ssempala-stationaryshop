# Sempala Stationery Shop Website

Official website for **Sempala Stationery Shop**, Kijabijjo, Gayaza, Uganda.

The site presents the shop's services and prices (in UGX), shows where to find us, and lets customers contact the shop quickly through WhatsApp, phone or email.

## Features

- Responsive design for phones, tablets and desktops
- Navy and orange theme taken from the shop's brochure
- Header with navigation and footer with contact details
- Service cards that slide in from the left and right
- JavaScript animations (scroll reveal, hover effects, counters)
- UGX prices for each service
- WhatsApp chat links on every service
- "Email us" button
- Location and opening hours section
- SEO: meta tags, Open Graph tags, local business structured data

## Getting Started

1. Download or clone the project folder.
2. Open `index.html` in any browser.
3. To edit, open the folder in a code editor such as VS Code and change the HTML, CSS or JS files.

## Customising

| What to change | Where |
| --- | --- |
| Shop phone / WhatsApp number | WhatsApp links in `index.html` (format `https://wa.me/256XXXXXXXXX`) |
| Email address | The "Email us" button (`mailto:` link) |
| Prices | Service cards in `index.html` |
| Colours | CSS variables at the top of `css/style.css` |
| Images | `images/` folder |

## Colours

## SEO Checklist

- Unique `<title>` and meta description
- Keywords: stationery shop Gayaza, printing Kijabijjo, photocopy Gayaza, school supplies Uganda
- Alt text on all images
- LocalBusiness structured data (JSON-LD)
- Google Business Profile linked to the site

## Deployment

The site can be hosted for free on GitHub Pages, Netlify or Vercel. Upload the project folder and point your domain to it.
